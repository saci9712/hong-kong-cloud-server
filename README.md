## 同一台 2 核 4GB，为什么差了 20 美元

贵的那 20 美元买的是单核频率和端口带宽，不是内存。

两档 Mini 摊开比：vCPU 都是 2 核，内存都是 4GB，存储都是 40GB NVMe，月流量都是 1000GB。区别只有两个——CPU 从 EPYC 7763 的 3.5GHz 换成 Ryzen 9 9950X 的 5.7GHz，端口从 1Gbps 升到 2Gbps。为此每月多付 $20，涨幅 51%。

值不值得花，看负载类型：

- 跑 WordPress、静态站、轻量 API，请求处理时间短，3.5GHz 完全够，省下的钱可以多买几个月

- 需要同时扛更多并发连接、又不想加内存的，2Gbps 端口比 CPU 频率更实用

Pro 这一档反过来：EPYC Pro 是 8 核 16GB、$169，Ryzen Pro 是 6 核 16GB、$199，多两核还便宜 $30。跑多进程、多容器、核心数比频率更重要的业务，这一档的性价比方向是反的，别按“贵的更好”的直觉选。

**DDoS 防护的覆盖范围。** 首页写的最高清洗能力是 600 Gbps，但没说明哪些套餐免费包含、是否所有节点都适用。做游戏服这类容易被攻击的业务，这点值得单独问。

**香港云服务器需要备案吗？** 不需要。香港机房不在内地备案体系内，解析域名、开服务即可用，这是很多人选香港而不是内地节点的直接原因。

**部署要等多久？** 官方写的是 1–5 分钟，支付成功后自动部署，完成后邮件发 IP 和登录凭据。不是即时开通，但也不用等工单。
